# RouteMind-AI — API Specification

## Endpoints

- GET /api/health: Health status
- GET /api/orders: List all active delivery orders
- GET /api/vehicles: List fleet vehicles
- GET /api/drivers: List driver profiles
- GET /api/traffic-events: List live traffic events
- POST /api/optimize: Run Google OR-Tools VRP Solver
- POST /api/simulate: Simulate real-world disruption & calculate business impact
- GET /api/analytics: Fleet performance metrics & savings trend
